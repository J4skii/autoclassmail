============================================
  PRAETO EMAIL AUTOMATION - SETUP GUIDE
============================================

WHAT THIS DOES
--------------
Monitors the admin6@praeto.co.za inbox.
When emails arrive, it classifies them
(Claims, Quotes, Servicing, Follow-ups)
and sends a digest to manager@praeto.co.za.

Runs silently in the background.
Starts automatically when Windows starts.


WHAT YOU NEED
-------------
- Windows server (any version)
- The 3 files below in the same folder:
    praeto-email.exe
    praeto_automation_config_v2.json
    .env


STEP 1 - CREATE A FOLDER
------------------------
Create this folder on the server:
    C:\PraetoEmail\

Copy these 3 files into it:
    praeto-email.exe
    praeto_automation_config_v2.json
    .env


STEP 2 - FILL IN CREDENTIALS
-----------------------------
Open the .env file with Notepad.
Replace "your_password_here" (x2) with
the real password for admin6@praeto.co.za.

Save and close.


STEP 3 - TEST IT RUNS
----------------------
Double-click praeto-email.exe

You should see it connect and check emails.
A digest will be sent to manager@praeto.co.za.

If you see an error, check the password in .env.


STEP 4 - INSTALL AS A BACKGROUND SERVICE
-----------------------------------------
Double-click install-service.bat

This registers the app to:
  - Run silently in the background
  - Start automatically when Windows starts
  - Restart itself if it crashes

After running it, you can close the window.
The service is now running.


STEP 5 - VERIFY IT IS RUNNING
------------------------------
Open Task Scheduler (search in Start Menu).
Look for "Praeto Email Automation" in the list.
Status should show "Running".


TO STOP THE SERVICE
-------------------
Double-click uninstall-service.bat
OR
Open Task Scheduler and delete "Praeto Email Automation"


PROBLEMS?
---------
- Wrong password    → edit .env, re-run install-service.bat
- Not sending email → check SMTP_PORT (try 465 if 587 fails)
- Need to change who gets the digest → edit DIGEST_TO_EMAIL in .env
